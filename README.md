# BharatAgri AI 🌾

BharatAgri AI is an AI-powered smart farming platform designed to help Indian farmers make better decisions using artificial intelligence.

## Features
- 🌦 Weather Forecast
- 🌱 AI Crop Advisor
- 📷 Disease Detection
- 💧 Irrigation Guidance
- 🧪 Fertilizer Recommendation
- 🗣 Multi-language Support

## Mission
Empowering every Indian farmer with AI.
